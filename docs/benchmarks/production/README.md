# Source-migration and load-context controls

Earlier production no_std/rename source comparison and follow-up controls; distinct from current17ab assembly/SIMD snapshots.

These are paired public-consumer observations, not an all-backend competitor grid. Keep process CPU and wall clocks separate. The original candidate became fast when the literal unchanged ELF/metadata were copied to another inode/path; a compiler or no_std cause was not established. PMU profiling was unavailable. Preserve those controls when interpreting apparent source migration regressions.

Original CSV and `.original.json` files retain the original bytes. Their
embedded paths, commit IDs and archive references are historical identifiers,
not active documentation links. Original and current paths and hashes are
recorded in the [retention manifest](../retention.json).
